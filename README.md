# Atharv Tekurkar's portfolio

A static, single-page portfolio designed as an editorial research note. It is ready for GitHub Pages at <https://tekurkaa.github.io/>.

## Update the site

- Edit `index.html` for copy, links, and project details.
- Edit `styles.css` for layout and visual styling.
- Replace the images in `assets/images/` when newer portrait or photography selections are available. Keep the filenames, or update their references in `index.html`.
- The SEC chart uses derived values committed in the [SEC Risk Shift Tracker metrics](https://github.com/tekurkaa/sec-risk-shift-tracker/tree/main/data/metrics). Update the chart and its description together if the source data changes.

No build step is required. Open `index.html` locally or serve the folder with any static web server.

## Content notes

Professional history and project descriptions were drafted from Atharv's September 2026 résumé and public project repositories. The Terminus image is a capture of the application's demo mode, not a verified performance result. The three photography images and portrait were reused from Atharv's previous public portfolio pending a new selection.

The site intentionally omits the résumé's phone number. Add a downloadable résumé only after deciding which contact details should be public.
